## 本轮已落地

- 共用固定侧栏、紧凑页头与白色内容区，移除占据首屏的装饰标题、重复流程说明。窄屏改为顶部导航。
- 知识库以文献目录、章节段落和原文阅读为主体；增加文献标题搜索，默认聚焦可引用段落。
- 导入改为侧边抽屉，支持背景遮罩、独立滚动、键盘焦点循环、Escape 关闭和返回触发按钮。审核页也可直接打开导入。
- 统一主次按钮、表单、错误和禁用原因。规范文本、技术引用结构、自动提取控制收进详情。
- 原文证据与知识整理并排；审核说明和确认按钮放到整理侧顶部。证据队列独立滚动，多条草稿引文折叠，避免把操作挤到上百条记录之后。

- `npm run build`：TypeScript / Vite 通过；`npm run check:api-errors` 六类错误检查通过。
- Codex 浏览器，真实 API / Worker，独立库 `tcm_vib62_vib93_test`：空态→导入合成 TXT→自动解析→选原文→精确证据→填写核对说明→审核→知识草稿，成功；刷新后草稿和审核范围重新读取。

- 1440×960 实际已有文献页面截图；1280×900 隔离工作区页面宽度 1265px（扣除滚动条）且无横向溢出，原文证据按钮底部约 837px。
- 1280×900 审核操作自动进入视口，确认按钮底部约 517px；核对空说明时禁用原因可见。
